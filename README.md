# Nordhordland i 3D

Interaktivt 3D-kart over Nordhordland bygget med [MapLibre GL JS](https://maplibre.org/).

Live side: https://sondreolsen.github.io/nordhordland-3d-kart/

## Funksjoner
- Ekte 3D-terreng fra høydedata (terrain-RGB)
- Fire byttbare karttjenester: Kartverkets topografiske kart, gråtone, sjøkart, samt Esri flyfoto
- Stedssøk mot Geonorges stedsnavn-API, avgrenset til Nordhordland
- Kontroller for kamerahelling, retning og terrengoverdriving
